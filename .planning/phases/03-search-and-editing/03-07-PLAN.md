  <name>Task 1: Fix text edit undo group flush and add content_text to snapshots</name>
  <files>src/store/treeStore.ts</files>
  <action>
Fix two bugs in the `updateContent()` function's undo group flush logic (around line 465-472):

**Bug 1: Wrong after_json format.** The current code passes `JSON.stringify(content)` as after_json, which is the raw TipTap JSON content of the NEW keystroke being typed. This is wrong in two ways:
- It's raw TipTap JSON, not wrapped in `{id, content}` format that Rust's text_edit handler expects
- It's the content of the current keystroke, not the final content of the PREVIOUS completed group
- If the user switched nodes, `content` is from the new node but `nodeIdForGroup` is from the old node

**Fix:** Replace the after_json in the `updateContent` flush (lines 465-472) with the correct value. After computing `nodeIdForGroup`, look up the node's current content from the tree state (which hasn't been optimistically updated yet at this point in the function):

```typescript
// In the shouldStartNewGroup(id, now) === true branch, after computing nodeIdForGroup:
const prevGroupNode = findNodeById(get().nodes, nodeIdForGroup)
const afterSnapshot = prevGroupNode
  ? { id: nodeIdForGroup, content: prevGroupNode.content, content_text: extractText(prevGroupNode.content) }
  : { id: nodeIdForGroup, content, content_text: extractText(content) }

recordUndoStepIpc(
  'text_edit',
  nodeIdForGroup,
  JSON.stringify(prevGroup.startSnapshot),
  JSON.stringify(afterSnapshot),
  prevGroup.groupKey
).catch((e) => console.warn('Failed to record undo step for text group:', e))
```

**Bug 2: Missing content_text in snapshots.** The startGroup snapshot (line 477) and the undo() flush snapshot (line 804) both lack `content_text`. Rust's text_edit handler defaults to `""` when missing, which clears FTS index text on undo.

**Fix startGroup snapshot** (line 476-478): Add content_text:
```typescript
const snapshot = currentNode
  ? { id: currentNode.id, content: currentNode.content, content_text: extractText(currentNode.content) }
  : { id, content, content_text: extractText(content) }
```

**Fix undo() flush snapshot** (line 803-804): Add content_text to the after_json:
```typescript
await recordUndoStepIpc(
  'text_edit',
  nodeIdForGroup,
  JSON.stringify(pending.startSnapshot),
  JSON.stringify({ id: currentNode.id, content: currentNode.content, content_text: extractText(currentNode.content) }),
  pending.groupKey
)
```

Do NOT change the structural undo recording (createNode, deleteNode, indentNode, etc.) — those already use `JSON.stringify(node)` from getNodeIpc which includes all fields.

Add a `console.log('[undo] flush text group:', nodeIdForGroup, 'before keys:', Object.keys(prevGroup.startSnapshot))` at flush time for debug visibility.
