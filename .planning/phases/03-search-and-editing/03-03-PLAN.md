    1. Create `src-tauri/src/commands/tags.rs` with IPC commands (all `#[tauri::command]` + `#[specta::specta]`):

       a) `get_all_tags(state) -> Result<Vec<TagCount>, AppError>`:
          - SELECT tag, COUNT(*) as count FROM node_tags GROUP BY tag ORDER BY count DESC
          - TagCount struct: { tag: String, count: i64 } with #[derive(Serialize, specta::Type)]

       b) `get_tags_matching(state, prefix: String) -> Result<Vec<String>, AppError>`:
          - SELECT DISTINCT tag FROM node_tags WHERE tag LIKE ?1 ORDER BY tag LIMIT 10
          - Bind `format!("{}%", prefix)` for prefix matching

       c) `sync_node_tags(state, node_id: String, tags: Vec<String>) -> Result<(), AppError>`:
          - DELETE FROM node_tags WHERE node_id = ?1
          - For each tag: INSERT INTO node_tags (node_id, tag) VALUES (?1, ?2)
          - This is a full replace strategy — simple and correct

    2. Update `mod.rs` and `lib.rs` to register all three tag commands.

    3. Add integration test `test_tag_indexing` to `db_tests.rs`:
       - Create a node, call sync_node_tags with ["rust", "tauri"]
       - Call get_all_tags, assert both tags appear with count 1
       - Call get_tags_matching("ru"), assert returns ["rust"]
       - Create second node with tag "rust", call get_all_tags, assert "rust" count = 2

    4. Add IPC wrappers to `src/store/ipc.ts`:
       - `getAllTagsIpc()`: returns TagCount[]
       - `getTagsMatchingIpc(prefix: string)`: returns string[]
       - `syncNodeTagsIpc(nodeId: string, tags: string[])`: returns void

    5. Install @tiptap/suggestion: `npm install @tiptap/suggestion`

    6. Create `src/extensions/HashtagNode.tsx` — TipTap Node extension:
       - `Node.create({ name: 'hashtag', group: 'inline', inline: true, selectable: false, atom: true })`
       - `addAttributes()`: returns `{ tag: { default: null } }`
       - `parseHTML()`: `[{ tag: 'span[data-hashtag]' }]`
       - `renderHTML()`: `['span', mergeAttributes({ 'data-hashtag': node.attrs.tag, class: 'hashtag' }, HTMLAttributes), '#' + node.attrs.tag]`
       - `addNodeView()`: Return a React node view that renders a clickable span. On click, it should trigger search filtered by that tag. Pass an `onTagClick` callback via extension options.
       - `addProseMirrorPlugins()`: Use `Suggestion` from `@tiptap/suggestion`:
         - `char: '#'`

         - `items: async ({ query }) => query.length >= 2 ? await getTagsMatchingIpc(query) : []` (minimum 2 chars per user decision)
         - `command: ({ editor, range, props }) => editor.chain().focus().deleteRange(range).insertContent({ type: 'hashtag', attrs: { tag: props } }).run()`
         - `render()`: Return a suggestion popup renderer. Create a simple React-based dropdown positioned near the cursor using `tippy.js` or manual absolute positioning via `clientRect`. Show matching tags as a list, arrow keys to navigate, Enter to select. Use a Portal to document.body with z-index: 1000 (above cmdk overlay).

    IMPORTANT: HashtagNode must be an atom Node (not a Mark) — hashtags are atomic units, not text ranges.
    IMPORTANT: Suggestion popup must render via React portal to document.body to avoid overflow clipping.
    IMPORTANT: Verify JSON round-trip: editor.getJSON() must serialize hashtag nodes correctly, and editor.setContent(json) must restore them.
