FIX A -- Lower query threshold (line 209):
Change `if (query.length < 2) return []` to `if (query.length < 1) return []`. This allows the popup to appear after typing just "#a" (1 character) instead of requiring "#ab" (2 characters).

FIX B -- Add "create new tag" option when no matches:
Modify the items callback to append a create-new-tag option when the IPC returns no matches (or when the query doesn't exactly match an existing tag). The items array is string[], so use a prefix convention like `__create__:tagname` to signal the create action:

```typescript
items: async ({ query }) => {
  if (query.length < 1) return []
  try {
    const matches = await getTagsMatchingIpc(query)
    // If no exact match exists, offer to create
    const exactMatch = matches.some(
      (m) => m.toLowerCase() === query.toLowerCase()
    )
    if (!exactMatch && query.trim().length > 0) {
      matches.push(`__create__:${query.trim()}`)
    }
    return matches
  } catch {
    // On error, still offer to create the tag
    return query.trim().length > 0 ? [`__create__:${query.trim()}`] : []
  }
},
```

Then update the `command` callback to handle the create prefix:
```typescript
command: ({ editor, range, props: tag }) => {
  const actualTag = typeof tag === 'string' && tag.startsWith('__create__:')
    ? tag.slice('__create__:'.length)
    : tag
  editor
    .chain()
    .focus()
    .deleteRange(range)
    .insertContent({ type: 'hashtag', attrs: { tag: actualTag } })
    .run()
},
```
