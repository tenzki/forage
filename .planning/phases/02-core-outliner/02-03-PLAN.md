  <files>src/components/Outliner/NodeEditor.tsx, src/components/Outliner/NodeRow.tsx, src/store/treeStore.ts</files>
  <action>
1. Add new store actions to `src/store/treeStore.ts`:
   - `createNode(parentId, afterNodeId)`: Computes position via `positionForInsertAfter`, calls `createNodeIpc` with `nodeType: "note"` and empty ProseMirror doc `{ type: "doc", content: [{ type: "paragraph" }] }`, optimistically inserts into local tree, returns new node id for focus management.
   - `deleteNode(id)`: Calls `deleteNodeIpc(id)`, removes from local tree, returns the id of the node that should receive focus (previous sibling or parent).
   - `updateContent(id, content)`: Calls `updateNodeIpc(id, content, null, null, null)` to persist. Debounce with 300ms — update local tree immediately but throttle IPC calls.
   - `indentNode(id)`: Find previous sibling. If none, no-op. Otherwise call `moveNodeIpc(id, prevSibling.id, positionAtEndOfPrevSiblingChildren)`. Update local tree.
   - `outdentNode(id)`: Find parent. If parent is root (parent_id null), no-op. Otherwise call `moveNodeIpc(id, parent.parent_id, positionAfterParent)`. Update local tree.
   - `reorderNode(id, direction)`: For 'up', swap with previous sibling's position. For 'down', swap with next sibling's position. Call `moveNodeIpc`. Update local tree.
   - `moveNode(id, newParentId, newPosition)`: Direct wrapper for `moveNodeIpc`, updates local tree.

2. Create `src/components/Outliner/NodeEditor.tsx`:
   - Create `OutlinerKeys` TipTap Extension using `Extension.create({ name: 'outlinerKeys', addKeyboardShortcuts() { ... } })`.
   - Keyboard shortcuts (return `true` to prevent default):
     - `Enter`: Call `createNode(node.parent_id, node.id)` to create sibling below. Focus the new node.
     - `Tab`: Call `indentNode(node.id)`. Prevents browser/TipTap default Tab.
     - `Shift-Tab`: Call `outdentNode(node.id)`. Prevents browser Shift-Tab.
     - `Backspace`: If `editor.isEmpty`, call `deleteNode(node.id)`, focus previous node. Otherwise return `false` (allow normal backspace).
     - `Alt-ArrowUp`: Call `reorderNode(node.id, 'up')`.
     - `Alt-ArrowDown`: Call `reorderNode(node.id, 'down')`.
     - `Alt-ArrowLeft`: Call `outdentNode(node.id)` (same as Shift-Tab per user decision).
     - `Alt-ArrowRight`: Call `indentNode(node.id)` (same as Tab per user decision).
   - Pass store actions via `OutlinerKeys.configure({ ... })` using the extension options pattern.
   - Configure TipTap `useEditor` with:
     - `StarterKit.configure({ heading: false, blockquote: false, codeBlock: false, horizontalRule: false, bulletList: false, orderedList: false, listItem: false })` — disable everything except paragraph/text for single-line nodes
     - `OutlinerKeys.configure({ onEnter, onIndent, onOutdent, onDeleteEmpty, onMoveUp, onMoveDown, onMoveLeft, onMoveRight })`
     - `content`: node's ProseMirror JSON content
     - `onUpdate`: debounced `updateContent(nodeId, editor.getJSON())`
   - Editor component renders `<EditorContent editor={editor} />`

3. Update `src/components/Outliner/NodeRow.tsx`:
   - **Performance pattern from RESEARCH.md:** Only mount TipTap for the currently focused/editing node. Render a plain `<span>` with `node.data.name` for all other nodes.
   - Track which node is "editing" via a `editingNodeId` in the store or local state.
   - Click on a node's text area sets it as editing (mounts TipTap).
   - Blur or navigating away unmounts TipTap for that row.
   - This avoids creating 1000 ProseMirror instances in a large tree.

**Critical from RESEARCH.md:**
- TipTap Enter handler MUST return `true` to prevent TipTap from creating a new paragraph inside the node
- Tab handler MUST return `true` to prevent browser focus traversal
- Only ONE TipTap instance should be live at a time (focused node)
- Optimistic position tracking: when creating nodes rapidly (Enter held down), update local position list before IPC response
