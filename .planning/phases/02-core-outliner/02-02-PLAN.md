1. Create `src/store/ipc.ts` — thin async wrappers around `commands` from bindings.ts that unwrap `Result<T, E>` and throw on error:
   ```typescript
   import { commands } from '../lib/bindings'
   import type { Node } from '../lib/bindings'

   export async function loadChildren(parentId: string | null): Promise<Node[]> {
     const result = await commands.getChildren(parentId)
     if (result.status === 'error') throw new Error(JSON.stringify(result.error))
     return result.data
   }

   export async function createNodeIpc(...): Promise<Node> { /* unwrap pattern */ }
   export async function updateNodeIpc(...): Promise<Node> { /* unwrap pattern */ }
   export async function moveNodeIpc(...): Promise<Node> { /* unwrap pattern */ }
   export async function deleteNodeIpc(...): Promise<void> { /* unwrap pattern */ }
   export async function getNodeIpc(id: string): Promise<Node> { /* unwrap pattern */ }
   ```

2. Create `src/store/treeStore.ts` — Zustand store in controlled mode for react-arborist:
   - **State:** `nodes: TreeNode[]`, `zoomedNodeId: string | null`, `breadcrumb: { id: string; name: string }[]`, `isLoading: boolean`
   - **Actions:**
     - `loadTree()`: Calls `loadChildren(zoomedNodeId)`, converts to `TreeNode[]` via `nodeToTreeNode`, then recursively loads children for non-collapsed nodes (lazy hydration — load 2 levels deep on initial mount for small trees, lazy expand beyond that). Sets `nodes`.
     - `toggleNode(id: string)`: Calls `updateNodeIpc(id, null, null, !currentCollapsed, null)` to persist collapsed state, then updates local store. If expanding, loads children for the expanded node via `loadChildren(id)`.
     - `zoomIn(id: string)`: Sets `zoomedNodeId = id`, rebuilds breadcrumb by walking parent chain via `getNodeIpc`, then calls `loadTree()`. **Per user decision: update the window title to the zoomed node's text** by calling `getCurrentWindow().setTitle(nodeName)` from `@tauri-apps/api/window`. Use `extractText` on the node's content to get the plain text name.
     - `zoomOut(targetId: string | null)`: Sets `zoomedNodeId = targetId` (null = Home), rebuilds breadcrumb, calls `loadTree()`. **Per user decision: if targetId is null (Home), reset window title to "ai-chat"** via `getCurrentWindow().setTitle('ai-chat')`. If zooming to an intermediate ancestor, set the title to that ancestor's name.
   - Use `zustand` create function (not with middleware for now — keep simple).
   - Import `TreeNode`, `nodeToTreeNode`, `extractText` from `src/types/tree.ts`.
   - Import IPC wrappers from `src/store/ipc.ts`.
   - Import `getCurrentWindow` from `@tauri-apps/api/window` for title updates.

**Critical patterns from RESEARCH.md:**
- react-arborist expects `children: []` (empty array) for expandable nodes, NEVER `undefined`
- Always use controlled `data` prop, never `initialData`
- Load children lazily on toggle — do NOT load entire tree eagerly
- Breadcrumb is built by walking parent chain via getNodeIpc calls
