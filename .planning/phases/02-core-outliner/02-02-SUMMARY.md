## Decisions Made

- `moveNodeIpc` uses direct `invoke('move_node', ...)` rather than `commands.moveNode` — the move_node command was added to Rust in Plan 01 Task 2, but `bindings.ts` is auto-generated by tauri-specta only on `cargo tauri dev/build`. Using direct invoke() avoids a missing-binding compile error until the next Tauri build regenerates the bindings.
- `@tauri-apps/api` installed as npm dependency to support `getCurrentWindow().setTitle()` for window title updates in zoomIn/zoomOut
- react-arborist Tree controlled via `data` prop + `onToggle` override — internal arborist toggle state is bypassed entirely so the Zustand store remains single source of truth
- Lazy hydration strategy: `loadChildren` 2 levels deep on mount, 1 level on expand — avoids loading the full tree for large databases
