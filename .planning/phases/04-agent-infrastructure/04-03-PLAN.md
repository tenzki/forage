Key Suggestion config differences from HashtagNode:

- `startOfLine: false` (locked decision: trigger anywhere)
- `allowSpaces: true` (args can contain spaces: '/research quantum computing')

**src/store/agentStore.ts**: Zustand store for agent operations.

```typescript
interface ActiveGeneration {
  nodeId: string        // triggering node
  ghostNodeId: string   // child node receiving streamed content
  skillId: string
  args: string
  tokens: string        // accumulated streamed text
  status: 'streaming' | 'complete' | 'error' | 'cancelled'
}

interface AgentStore {
  activeGenerations: Map<string, ActiveGeneration>  // keyed by nodeId (per pitfall #7)

  // Core action: triggered by slash command selection
  invokeSkill(nodeId: string, skillId: string, args: string): Promise<void>

  // Context building
  buildContextMessages(nodeId: string): Promise<Array<{ role: 'user' | 'assistant', content: string }>>

  // Streaming (used by agent-event listener)
  appendToken(nodeId: string, delta: string): void
  finalizeGeneration(nodeId: string): void

  // Cancellation
  cancelGeneration(nodeId: string): Promise<void>
}
```

**buildContextMessages(nodeId)**:
- Call `getAncestorsIpc(nodeId)` to get ordered ancestor chain (root to parent)
- For each ancestor, call `getNodeIpc(ancestor.id)` to get full node data
- Map to messages: nodes with `node_type === 'agent_response'` become `{ role: 'assistant', content }`, all others become `{ role: 'user', content }`
- Extract text content using the existing `extractText()` from `src/types/tree.ts`
- Include the triggering node itself as the final user message
- Return the messages array in order (oldest ancestor first)

**invokeSkill(nodeId, skillId, args)**:
- Call `buildContextMessages(nodeId)` to get conversation context
- Look up the skill from SKILLS array to get outputMode
- Store command in node metadata: call `updateNodeIpc(nodeId, null, null, null, JSON.stringify({ slashCommand: { skillId, args } }))` — per locked decision, command stored in metadata
- Create a ghost child node via `createNodeIpc(nodeId, position, 'agent_response', emptyContent, { partial: true }, null)` — with `partial: true` metadata per pitfall #5
- Add to `activeGenerations` map keyed by nodeId
- Send prompt to sidecar: `agentCommandIpc({ type: 'prompt', id: requestId, text: args, systemPrompt: 'You are a helpful assistant...', messages: contextMessages, skill: skillId })`

**cancelGeneration(nodeId)**:
- Send `agentCommandIpc({ type: 'abort' })` to sidecar
- Remove ghost node or mark as partial
- Clear from activeGenerations

**appendToken and finalizeGeneration**: Placeholder implementations — full streaming wiring happens in Plan 04. For now, appendToken accumulates tokens in the generation entry, finalizeGeneration marks status as 'complete'.

**src/components/Outliner/NodeEditor.tsx**: Add SlashCommand to the TipTap extensions array:

- Add to extensions array with `.configure({ onSkillInvoked: (skillId, args) => { useAgentStore.getState().invokeSkill(nodeId, skillId, args) } })`
- Use the same configure() callback pattern as OutlinerKeys to avoid stale closures
- The nodeId should come from the current editing node context (same pattern as other keyboard handlers)
