**src/store/agentStore.ts**: Zustand store for agent operations.

```typescript
// Token estimation constant — conservative estimate for context budget
const MAX_CONTEXT_TOKENS = 100_000  // ~100k tokens, well under 128k/200k model limits
const RECENT_MESSAGES_TO_KEEP = 4   // Always keep the most recent N messages in full

interface ActiveGeneration {
  nodeId: string        // triggering node
  ghostNodeId: string   // child node receiving streamed content
  skillId: string
  args: string
  tokens: string        // accumulated streamed text
  status: 'streaming' | 'complete' | 'error' | 'cancelled'
}

interface AgentStore {
  activeGenerations: Map<string, ActiveGeneration>  // keyed by nodeId (per pitfall #7)

  // Core action: triggered by slash command selection
  invokeSkill(nodeId: string, skillId: string, args: string): Promise<void>

  // Context building (with summarization)
  buildContextMessages(nodeId: string): Promise<Array<{ role: 'user' | 'assistant', content: string }>>

  // Streaming (used by agent-event listener)
  appendToken(nodeId: string, delta: string): void
  finalizeGeneration(nodeId: string): void

  // Cancellation
  cancelGeneration(nodeId: string): Promise<void>
}
```

**buildContextMessages(nodeId)** — now with context summarization per locked decision:
1. Call `getAncestorsIpc(nodeId)` to get ordered ancestor chain (root to parent)
2. For each ancestor, call `getNodeIpc(ancestor.id)` to get full node data
3. Map to messages: nodes with `node_type === 'agent_response'` become `{ role: 'assistant', content }`, all others become `{ role: 'user', content }`
4. Extract text content using the existing `extractText()` from `src/types/tree.ts`
5. Include the triggering node itself as the final user message
6. **Token counting**: Implement `estimateTokens(text: string): number` — use chars/4 heuristic (good enough for budget estimation, no tokenizer dependency needed)
7. **Summarization check**: Sum estimated tokens across all messages. If total <= MAX_CONTEXT_TOKENS, return messages as-is. If total > MAX_CONTEXT_TOKENS:
   a. Split messages into two groups: "older" (all except the last RECENT_MESSAGES_TO_KEEP) and "recent" (last RECENT_MESSAGES_TO_KEEP messages)
   b. Send the "older" messages to the sidecar for summarization: `agentCommandIpc({ type: 'summarize', id: requestId, messages: olderMessages })` — the sidecar's `summarize` handler (added in Plan 01 Task 1) calls the LLM to produce a concise summary
   c. Listen for `{ type: 'summary', id: requestId, content: '...' }` on `agent-event` (same one-shot listener pattern as settings)
   d. Replace the "older" messages with a single `{ role: 'user', content: '[Context summary]: ' + summaryContent }` message
   e. Return `[summaryMessage, ...recentMessages]`
8. Return the messages array in order (oldest ancestor first, or summary + recent)

**invokeSkill(nodeId, skillId, args)**:
- Call `buildContextMessages(nodeId)` to get conversation context (with summarization if needed)
- Look up the skill from SKILLS array to get outputMode
- Store command in node metadata: call `updateNodeIpc(nodeId, null, null, null, JSON.stringify({ slashCommand: { skillId, args } }))` — per locked decision, command stored in metadata
- Create a ghost child node via `createNodeIpc(nodeId, position, 'agent_response', emptyContent, { partial: true }, null)` — with `partial: true` metadata per pitfall #5
- Add to `activeGenerations` map keyed by nodeId
- Send prompt to sidecar: `agentCommandIpc({ type: 'prompt', id: requestId, text: args, systemPrompt: 'You are a helpful assistant...', messages: contextMessages, skill: skillId })`

**cancelGeneration(nodeId)**:
- Send `agentCommandIpc({ type: 'abort' })` to sidecar
- Remove ghost node or mark as partial
- Clear from activeGenerations

**appendToken and finalizeGeneration**: Placeholder implementations — full streaming wiring happens in Plan 04. For now, appendToken accumulates tokens in the generation entry, finalizeGeneration marks status as 'complete'.
