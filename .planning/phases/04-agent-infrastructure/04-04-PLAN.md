**src-sidecar/index.ts**: Upgrade the placeholder prompt handler to use pi-coding-agent:

1. Import `@mariozechner/pi-coding-agent` — use its RPC mode or SDK mode depending on what's available. If the package exposes a programmatic API (like `createAgentSession` or similar), use that. If it only works as a CLI with `--mode rpc`, then the sidecar IS the pi process and we should restructure accordingly.

**Fallback approach (if pi RPC integration is complex):** Use `@mariozechner/pi-ai` directly (pi-coding-agent bundles it) for the LLM call. This gives streaming without the full agent runtime:
```typescript
import { createProvider } from '@mariozechner/pi-ai'
// or use the specific provider SDK based on settings

const provider = createProvider('anthropic', { apiKey })
const stream = await provider.streamText({ model, messages, system })
for await (const chunk of stream) {
  process.stdout.write(JSON.stringify({ type: 'message_update', id: requestId, assistantMessageEvent: { type: 'text_delta', delta: chunk.text } }) + '\n')
}
process.stdout.write(JSON.stringify({ type: 'turn_end', id: requestId }) + '\n')
```

2. On `{ type: 'prompt', id, text, skill, messages, systemPrompt }` command:
   - Look up skill config from skills map
   - Get API key and model from saved settings (loaded via keystore)
   - Build messages array: skill systemPrompt + provided conversation messages + user text as final message
   - Stream response tokens, writing each as JSONL `{ type: 'message_update', id, assistantMessageEvent: { type: 'text_delta', delta } }` to stdout
   - On completion: write `{ type: 'turn_end', id }` then `{ type: 'agent_end', id }`
   - On error: write `{ type: 'error', id, message: '...' }`

3. On `{ type: 'abort' }`: Cancel the current streaming request (AbortController pattern).

4. Handle missing API key gracefully: respond with `{ type: 'error', id, message: 'No API key configured for provider X. Open Settings to add one.' }`

Important: Each JSONL line must end with `\n` only (no `\r\n`). Use `process.stdout.write()` not `console.log()` (console.log adds its own newline handling).

**src/store/agentStore.ts**: Complete the streaming implementation:

1. **initAgentListener()**: Call once on app startup (from main.tsx or OutlinerView mount). Sets up `listen('agent-event', callback)` that:
   - Parses each event payload as JSON
   - Matches `id` field to find the correct ActiveGeneration entry
   - On `message_update` with `text_delta`: call `appendToken(nodeId, delta)`
   - On `turn_end`: call `finalizeGeneration(nodeId)`
   - On `agent_end`: clear the generation from activeGenerations
   - On `error`: set generation status to 'error', optionally show error in ghost node content

2. **appendToken(nodeId, delta)**: Full implementation:
   - Find generation by nodeId in activeGenerations
   - Append delta to `tokens` string
   - Convert accumulated text to TipTap JSON content (simple paragraph with text node)
   - Call `useTreeStore.getState().updateNodeLocally(ghostNodeId, { content: tiptapJson })`
   - Do NOT call IPC — per anti-pattern: no persistence on every token

3. **finalizeGeneration(nodeId)**: Full implementation:
   - Get final accumulated content from generation
   - For **children mode** (ask, research): persist ghost node content to DB via `updateContent(ghostNodeId, finalContent, extractText(finalContent))`
   - Remove `partial: true` from ghost node metadata via `updateNodeIpc`
   - For **brainstorm**: Parse accumulated text, split on newline/bullet points, create separate child nodes for each idea (each with node_type='agent_response')
   - Mark generation status as 'complete'

4. **Inline (replace) mode** for AGNT-03:
   - When a skill has `outputMode: 'replace'`: do NOT create a ghost child node
   - Instead, stream tokens directly into the triggering node's content via `updateNodeLocally`
   - On finalize: persist the updated content to the triggering node
   - The triggering node's node_type remains unchanged (it stays as user content)

5. **cancelGeneration(nodeId)**: Full implementation:
   - Send abort to sidecar
   - If ghost node exists and has content: keep it with `partial: true` metadata
   - If ghost node is empty: delete it via `deleteNodeIpc`
   - Clear from activeGenerations
