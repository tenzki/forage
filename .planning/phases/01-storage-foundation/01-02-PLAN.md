    - create_node stores content as JSON string in SQLite
    - get_node returns the node by id, or error if not found
    - get_children with parent_id=None returns root nodes ordered by position ASC
    - get_children with parent_id=Some(id) returns children ordered by position ASC
    - update_node changes content, position, collapsed, metadata, and updates updated_at
    - delete_node removes the node (CASCADE removes children)
    - All commands use #[tauri::command] and #[specta::specta] annotations
  </behavior>
  <action>
Create `src-tauri/src/commands/mod.rs` re-exporting the nodes module.

Create `src-tauri/src/commands/nodes.rs` with five IPC handlers following RESEARCH.md Pattern 3:

**create_node(state, parent_id, position, node_type, content, metadata):**
- Generate UUID v4 via `uuid::Uuid::new_v4().to_string()`
- Serialize content to string via serde_json::to_string
- Use `sqlx::query()` with positional binds (?1, ?2, etc.) — NOT sqlx::query!() (no compile-time DB needed)
- Insert all columns including skill_id (None for now), metadata
- Set created_at and updated_at to Utc::now().to_rfc3339()
- Return the created node by calling get_node internally

**get_node(state, id):**
- `SELECT * FROM nodes WHERE id = ?1`
- Manual row extraction using `sqlx::query().fetch_one()` and `sqlx::Row` trait
- Map row columns to Node struct fields
- Return AppError::NotFound if no row

**get_children(state, parent_id):**
- `SELECT * FROM nodes WHERE parent_id IS ?1 ORDER BY position ASC`
- Use `IS` not `=` for NULL comparison (root nodes have parent_id IS NULL)
- Map rows to Vec<Node>

**update_node(state, id, content, position, collapsed, metadata):**
- All fields optional except id — only update provided fields
- Always update updated_at to current timestamp
- Return updated node

**delete_node(state, id):**
- `DELETE FROM nodes WHERE id = ?1`
- Return nothing on success, error if node not found

**Annotate every handler** with both `#[tauri::command]` and `#[specta::specta]`. Return `Result<T, AppError>` where AppError is the specta-typed error from Plan 01.

**Update lib.rs:**
- Add `mod commands;`
- Register all five commands in `collect_commands![]`
- Wire the invoke_handler from the tauri-specta builder
- Enable TypeScript binding generation at `../src/lib/bindings.ts` in debug builds

**Create `src/lib/` directory** and ensure the bindings.ts path target exists (tauri-specta will write to it on dev build).
